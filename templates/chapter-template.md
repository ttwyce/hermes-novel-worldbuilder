# 章节正文模板

> 本文件是 `novel-worldbuilder` 技能的写作模板。复制到正文目录后修改。

## 使用方式

1. 复制本文件到 `正文/卷X_XXX/第Y章.md`
2. 将「章节名」改为实际章节名
3. 删除示例文字，开始写作
4. 写完后执行「章节完成自检清单」（`references/chapter-completion-checklist.md`）

---

```markdown
# 第X章：章节名

[正文内容]
```

## 写作检查清单（20项，写完必查）

### 基础合规（4项）
- [ ] 字数在设定值±20%范围内（如设定3000字则2400-3600合格）
- [ ] POV仅跟主角，无切换
- [ ] 对话使用「」
- [ ] 无赫然/陡然/突然等禁用词

### 剧情质量（5项）
- [ ] 有核心事件
- [ ] 推进了至少1条剧情线
- [ ] 无同一借口重复3次以上
- [ ] 章末有钩子/悬念/笑点
- [ ] 有至少1个新信息/线索进入

### 伏笔检查（3项）
- [ ] 本章埋的新伏笔已登记
- [ ] 无与已建立设定矛盾之处
- [ ] 单章新埋伏笔不超过2个

### 场景一致性（3项）
- [ ] 场景与前后章衔接
- [ ] 人物位置与上一章末尾一致
- [ ] 时间不早于上一章

### 追踪文件更新（5项）
- [ ] 章节大纲已追加
- [ ] 编年史已追加
- [ ] 世界状态已更新
- [ ] 剧情线追踪已记录
- [ ] 角色弧光追踪已记录（如有变化）

**通过标准：20项中至少19项通过，第1-9项（P0硬性）必须100%通过**
