## 子代理（delegate_task）使用规范

### 核心限制（已知硬性上限）

| 参数 | 值 | 来源 |
|------|---|------|
| `max_concurrent_children` | 3 | config.yaml |
| 单次最大任务数 | 3 | delegate_task 限制 |
| 子代理超时 | 600s | 全局超时 |

### 大内容生成任务的失败模式

**失败场景**：同时给子代理分配5个大型任务（设定集2万字+、12个角色档案×500字等）

**症状**：所有子代理在600s后全部超时，`status: timeout`

**根因**：
1. 任务数超过 `max_concurrent_children=3`，部分任务被静默丢弃或排队异常
2. 单个任务内容太大（如完整的设定集），API 生成时间超过600s 超时阈值

### 正确做法：分块 + 小任务

**分块原则**：每批任务 ≤3 个，每任务文本量 ≤5000 字

**示例：首次创建项目分3批**

```
第一批（3个）：
  A. 生成设定集.md + 世界观/*.md + 世界状态.md（核心文件）
  B. 生成势力/势力分布.md + 人物/角色注册表.md + 人物关系图.md + 关系记录.md + 伏笔与钩子.md
  C. 生成大纲/剧情大纲.md + 大纲/分卷大纲.md + 大纲/章节大纲.md（含前5章）+ 大纲/编年史.md

第二批（3个）：
  A. 生成人物/角色档案/主角.md + 苏瑶.md + 姜雪.md + 叶琉璃.md
  B. 生成人物/角色档案/萧青竹.md + 林紫烟.md + 白洛妃.md + 赵妖儿.md
  C. 生成人物/角色档案/陈瑶光.md + 周若兰.md + 韩青罗.md + 柳飘絮.md + 其他人物.md

第三批（2个）：
  A. 生成写作指南/文风指南.md + 写作指南/写作规范.md
  B. 生成 README.md + SKILL.md（从技能目录复制）
```

**每批之间**：等上一批完全完成后再提交下一批。

### 紧急回退：子代理超时后的处理

如果子代理超时，按以下顺序处理：

1. **检查已生成的文件**：`find ~/novels/书名/ -type f`
2. **确认缺失文件列表**：对照 `references/structure-guide.md` 的「首次创建时必须生成的24个文件」
3. **主 agent 直接写**：不再用子代理，主 agent 直接用 `write_file` / Python 脚本生成剩余文件
4. **内容简化策略**：优先保核心文件（设定集.md / 世界观/力量体系.md / 人物/角色注册表.md / 大纲/章节大纲.md），其余可从略
