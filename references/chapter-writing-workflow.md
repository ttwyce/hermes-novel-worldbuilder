# 章节写入与追踪文件更新流程

> 2025-05-10 更新：子代理写入流程 + 超时/超限处理规范

---

## 当前正确流程（子代理版）

```
主Agent调用delegate_task(写第X章)
    ↓
子代理cat heredoc一次性写入（不受截断限制）
    ↓
主Agent验证字数：python3 verify_chapter.py 第X章.md 3000
    ↓
情况A：合格（2400-3600字）→ post_chapter.py 更新追踪
情况B：不足（<2400字）→ 重写本章
情况C：超限（>3600字）→ patch精简约合格
    ↓
验证追踪文件：grep "第X章" 大纲/进度看板.md
```

---

## 子代理超时处理（重要）

**症状**：子代理报告 `timeout`（600s）

**关键认知**：超时 ≠ 失败。文件通常已经写完，需要手动检查。

```bash
# 检查文件
ls -la 正文/卷X名称/第X章.md

# 验证字数
python3 verify_chapter.py 第X章.md 3000

# 根据结果处理：
# 合格 → post_chapter.py
# 不足 → delegate_task重写
# 超限 → patch精简
```

---

## 字数超限处理（常见！）

子代理通常写出目标的150-180%，需要手动精简约3000-3600字。

**精简约流程**：
1. `wc -l` 查看总行数，`tail -50` 确认结尾完整
2. 定位可精简内容（冗长内心独白/重复描写/过度铺陈结尾）
3. `patch(new_string="精简后承接", old_string="被删冗余段落")` 每次200-500字
4. 验证直到合格

**示例**（第5章从5315字精简至3420字）：
- 删除放学场景中重复的内心独白（-500字）
- 精简女主出场的冗长描写（-400字）
- 精简配角出场的对话旁白（-300字）
- 精简主角结尾独白（-200字）

## 追踪文件更新

```
post_chapter.py "书名" X 字数 "核心事件"
```

自动更新：进度看板 / 剧情线追踪 / 编年史 / 角色弧光追踪 / world_state

---

## 章节文件格式约束

```
# 第X章：章节名

[正文内容，禁止用---做叙事分段]

---

## 第X章审核报告  ← 文件中只保留一个---，位于正文末尾
```

**关键**：第一个独立行 `---` 之后才是审核报告，正文叙事内部用空行分隔。
