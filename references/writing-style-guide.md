# 写作风格指南：搞笑 vs 认真

> 适用：嘴强剑仙 / 系统流 / 搞笑修仙小说
> 基于12章实战经验总结

---

## 核心原则

**不是每句话都要搞笑。** 笑点要有节奏，该认真时要认真。

---

## 该认真的时候（禁止硬搞笑）

| 场景 | 风格 | 原因 |
|------|------|------|
| 战斗/比赛 | 认真描写招式、心理、结果 | 读者需要感受到紧张感 |
| 情感升温 | 叶琳/苏清雪的感情戏 | 认真才能让读者共鸣 |
| 关键转折 | 系统觉醒、反杀、高光时刻 | 需要压住节奏制造冲击力 |
| 伏笔揭露 | 陈朵朵身世等 | 严肃才有悬念 |
| 主角成长 | 等级提升、获得新能力 | 认真描写让读者有成就感 |

### 示例：正确

```markdown
陆天感觉到体内的灵力在咆哮。那种感觉就像是被困了十七年的野兽终于冲破了牢笼。

【系统提示：嘴炮等级 Lv.1 → Lv.2】
```

### 示例：错误（不该搞笑时搞笑）

```markdown
陆天感觉体内的灵力在咆哮，就像食堂大妈颠勺一样有力。
【系统】叮！恭喜你升级啦！就像泡面一样简单！
```

---

## 该搞笑的时候

| 场景 | 风格 | 示例 |
|------|------|------|
| 日常互动 | 吃饭、聊天、训练吐槽 | 角色互怼 |
| 嘴炮战斗 | 打嘴炮赢对手 | 吐槽系统的本质 |
| 配角出场 | 介绍新人/路人 | 可以夸张 |
| 系统反馈 | 吐槽系统的伤害提示 | 故意搞笑 |

---

## 克制原则

1. **同一笑点不重复**：第7章对石头吐槽，第11章不要再对石头吐槽
2. **主角吐槽不超过每章3次**：过多会让读者审美疲劳
3. **每章至少一段安静推进**：不要从头笑到尾
4. **角色出场不要每个都搞笑**：陆天可以吐槽，但叶琳/苏清雪更多是傲娇/高冷

---

## 常见错误

### 错误1：系统出现生硬
```markdown
# 错误
突然——【叮——】系统觉醒了！

# 正确：有铺垫
陆天感觉有什么东西在体内觉醒……
【系统：检测到宿主处于侮辱状态，启动嘴炮模式】
```

### 错误2：笑点模式雷同
```markdown
# 错误：每次都是"对手心态崩了"
对手1心态崩了
对手2心态崩了

# 正确：换不同的失败反应
对手1：脸色铁青
对手2：气得发抖
```

### 错误3：节奏前紧后松（第1-3章塞太多）
每章只推进1-2条线，不要把所有事件挤在一起。

## 章节自检清单

写完一章后检查：
- [ ] 笑点是否重复了前3章的模式？
- [ ] 感情戏是否认真在写？
- [ ] 战斗戏是否有紧张感？
- [ ] 主角吐槽是否超过3次？
- [ ] 章节结尾是否需要钩子？
