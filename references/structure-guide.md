# novel-worldbuilder 目录结构参考

> 本文件记录经过实际验证的小说项目目录结构。新建项目时参考此结构创建 `init_novel.py` 脚本。

## 完整目录结构

```
~/novels/
└── 《书名》/
    ├── SKILL.md                  # 从技能复制来的创作说明
    ├── README.md                 # 本书概览索引
    ├── 设定集.md                  # 完整设定集（主入口）
    ├── 世界观/
    │   ├── 世界观设定.md
    │   ├── 时代背景.md
    │   ├── 力量体系.md
    │   └── 世界状态.md            # 【动态】人物位置/物品/事件状态
    ├── 势力/
    │   └── 势力分布.md
    ├── 人物/
    │   ├── 角色注册表.md          # 核心索引：ID/状态/出场卷
    │   ├── 人物关系图.md          # ASCII关系网络
    │   ├── 关系记录.md            # 【追加型】关系变化历史
    │   ├── 伏笔与钩子.md          # 【动态】待回收伏笔/剧情钩子/线索
    │   ├── 角色档案/              # 每人一文件
    │   │   ├── 主角.md
    │   │   └── [配角].md
    │   └── 其他人物.md            # 配角汇总（便于快速浏览）
    ├── 大纲/
    │   ├── 剧情大纲.md            # 主线核心冲突 + ASCII流程图
    │   ├── 剧情线追踪.md          # 【新增】主/副/支/感情线进度
    │   ├── 进度看板.md            # 【新增】章节数/字数/伏笔回收/分卷完成率
    │   ├── 角色弧光追踪.md        # 【新增】角色成长变化记录
    │   ├── 分卷大纲.md
    │   ├── 章节大纲.md            # 【动态】每章核心事件/字数/场景/线条/伏笔
    │   └── 编年史.md              # 【动态】故事内时间排序
    ├── 写作指南/
    │   ├── 文风指南.md
    │   └── 写作规范.md
    └── 正文/
        ├── 卷一_铺垫与启程/
        ├── 卷二_对抗与成长/
        └── 卷三_高潮与收官/
```

## 动态文件说明

| 文件 | 更新频率 | 更新时机 |
|------|---------|---------|
| 大纲/章节大纲.md | 每章写完 | 追加本章记录 |
| 大纲/编年史.md | 每章写完 | 追加时间点 |
| 世界观/世界状态.md | 每章写完 | 更新人物/物品位置 |
| 人物/伏笔与钩子.md | 每章有伏笔时 | 追加新伏笔/钩子 |
| 大纲/剧情线追踪.md | 每章写完 | 记录线条推进情况 |
| 大纲/进度看板.md | 每章写完 | 更新章节数/字数 |
| 大纲/角色弧光追踪.md | 每章有变化时 | 记录弧光变化 |
| 人物/关系记录.md | 关系变化时 | 追加变更记录 |
| 人物/角色档案/*.md | 出场时 | 追加出场记录 |
